# **Outbook**
## A stealth ePub reader disguised as a corporate email client.

**What it is**  
Outbook is a client-side reading tool built for browsing local .epub files inside a familiar 3-panel interface (Left navigation, Middle inbox list, and Right reading pane). Everything runs entirely in your browser with zero server uploads.

**Features**
- Corporate Disguise: Looks like a standard work messaging portal at first glance.

- Boss Key: Hit Escape instantly to mask your reading view.

- Customizer Toolbar: Adjust fonts, sizing, and spacing on the fly.

- Progress Metrics: Real-time page counters and completion percentage tracking.

- Keyboard Navigation: Use J and K shortcuts to flip pages seamlessly.

- Local Persistence: Remembers your exact reading position so you never lose your spot.
